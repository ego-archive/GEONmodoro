# GEONmodoro

건스키와 함께하는 뽀모도로 데스크톱 펫 🐾

바탕화면 위에 항상 떠 있는 3D 건스키가 집중 시간과 휴식 시간을 함께 해요.

## 다운로드

[Releases](../../releases/latest)에서 받으세요.

- **GEONmodoro-Setup-x.x.x.exe**: 설치 버전 (권장)
- **GEONmodoro-Portable-x.x.x.exe**: 설치 없이 바로 실행

> 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요. **추가 정보 → 실행**을 누르면 돼요.

## 사용법

- **더블클릭**: 타이머 시작 / 일시정지
- **클릭**: 애교
- **드래그**: 이동 (들어 올리면 버둥버둥)
- **우클릭**: 메뉴 (시작/일시정지, 리셋, 건너뛰기, 설정, 종료)
- **설정**: 집중·휴식 시간, 건스키 크기, 조명 따뜻함
- 컴퓨터를 켜면 자동으로 실행돼요. 끄려면 윈도우 설정 → 앱 → 시작 프로그램에서 끄세요.

키보드를 치면 타이핑하고, 마우스를 움직이면 고개를 돌려 쳐다보고, 컴퓨터에서 소리가 나면 귀를 팔랑거려요. 키 입력은 "눌렸다"는 사실만 쓰고 어떤 키인지는 읽거나 저장하지 않아요.
